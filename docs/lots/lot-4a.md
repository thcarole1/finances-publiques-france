## Limites (affichées dans le rapport)

- Calcul mécanique, sans effet en retour (une économie budgétaire ne freine pas la croissance).
- Hypothèses constantes sur l'horizon ; pas de refinancement explicite (lot 4b).
- TVA : variation proportionnelle de tous les taux, sans effet sur la consommation.
